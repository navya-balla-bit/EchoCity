
# 🏙️ EchoCity — Smart City Issue Reporting Platform

EchoCity is a web-based platform designed to help communities report and track civic issues such as potholes, water leaks, garbage overflow, and broken streetlights.

## ✨ Features

- 📍 Interactive map using Leaflet and OpenStreetMap
- 📝 Civic issue reporting and tracking
- 🚦 Automatic priority scoring
- 🔎 Duplicate issue detection
- 📊 Live city analytics dashboard
- 🔄 Issue status tracking

## 🛠️ Technologies Used

- Frontend: HTML, CSS, JavaScript, Leaflet
- Backend: Node.js, Express.js
- Database: SQLite

## 🚀 Run Locally

1. Install Node.js.
2. Clone the repository:

   `git clone https://github.com/navya-balla-bit/EchoCity.git`

3. Open the project folder:

   `cd EchoCity`

4. Install dependencies:

   `npm install`

5. Start the application:

   `npm start`

6. Open `http://localhost:3000` in your browser.

## 🎯 Project Goal

To help communities report civic problems, identify high-priority issues, and monitor city issue statistics through a single dashboard.
